Loopweft

Loopweft and AI agents

Loopweft has no AI of its own. An AI agent you run yourself can build and check maps with its command line, by rules that keep the evidence honest.

Loopweft's command line, loopweft, can do everything the Studio does to a map: add variables and links (also as shorthand, Births -> Population (+)), name loops, add sources and cite them, tell a story step by step, check the map and export it. Every command answers in plain words or, with --json, in one JSON document, with exit codes an agent can act on. So an agent that runs commands on your computer, such as Claude Code or Codex, can do the work while you watch the map in the Studio.

The rules an agent is given

  • Change maps only through loopweft commands, never by editing the file's text, and look nowhere else on your computer: the guide and the command line's own help are all it needs.
  • Never guess a link's sign: take it from your brief, a source or the archetype. A link the agent suggests itself may carry the sign its reasoning gives, with the reasoning written on the link; when nothing settles it, ?, which Loopweft flags for you to decide.
  • Say where every link comes from, in its Basis field: your brief, the archetype, a source, or the agent's own suggestion. You can find every suggestion in the Studio's table, and keep, change or remove it.
  • Never invent evidence: add only sources you gave it, or ones it confirmed with a DOI lookup; never write a page number it has not seen. When unsure, leave a link uncited (Loopweft flags that too).
  • Check the map with loopweft validate before exporting, and export only with no errors.
  • Report at the end: what it changed, which links are its own suggestions, every ?, what is still uncited, and the files it made.

How to work with one

  1. Get the command line. For now it runs inside a copy of the repository (with Node 24: npm install, then npx loopweft); the desktop apps will install it for you.
  2. In the Studio, save your map into a folder of its own, then choose File › Work with an AI agent… and Copy agent instructions.
  3. Open your agent in that folder, paste the message, and say what you would like it to do.
  4. Watch: in Chrome or Edge, the open map follows each change the agent saves, with a note of what changed, and Undo goes back. If you have unsaved changes, the Studio asks which version to keep; it never merges.
  5. Read the agent's report, and check its changes before you rely on them.

loopweft guide --install <folder> also puts the guide in a folder, where Claude Code (.claude/skills/loopweft/SKILL.md) and Codex (AGENTS.md) find it by themselves.

For agents: the guide is SKILL.md (the same text as loopweft guide prints), and every command, with examples of what it prints, is in the command reference.
